# QuickVault 1.1.1

A fix release for daily phone use, on top of 1.1.0. Formats are unchanged:
1.1.1 opens and writes the same vault, archive and snapshot formats as
1.0.0 and 1.1.0 (spec 0015).

This file is the release record that 0012 §3 asks for. Everything in the
[1.0.0 record](1.0.0.md) about signing, build inputs, the security status
and known limitations still applies; this file lists only what changed and
what was checked for it.

## What changed (plan 0069)

- **Android updates install.** 1.0.0 and 1.1.0 both shipped with Android
  version code 1, so installers treated each release as the same build and
  could refuse the update ("conflicts with an existing package"). The APK
  now carries `major·10000 + minor·100 + patch` (1.1.1 → 10101), so it
  updates over 1.0.0 and 1.1.0.
- **No freeze after a quick app switch.** Leaving the app and returning
  quickly could leave a screen that neither locked nor reacted to taps: a
  screen update resent after its local UI connection dropped in the
  background was applied twice. Updates are now numbered, applied once and
  confirmed on their own connection (vendored dioxus-desktop).
- **Switching apps keeps the vault open.** On Android the vault locks once
  the inactivity time runs out, in the background or on return, instead of
  as soon as the app leaves the screen. Screen lock, and a phone that slept
  meanwhile, still lock at once.
- **5-minute auto-lock** instead of 1 minute, on every platform.
- **Paste works.** Android text fields have their long-press Paste again;
  on Linux, right-clicking a text field offers Paste, Delete and Select
  All. Copy and cut work in plain fields being edited; shown values and
  password fields still copy only through the app's clearing clipboard.
- **Groups are listed by name.**
- **Copy messages.** Copying an empty or missing field says "Nothing to
  copy" instead of claiming the clipboard is unavailable; a copy replaced
  by another one is reported as such; other failures say to try again.

Specs 0004 §7.3, 0008 §1.4 and 0009 §1.8/§7 were amended for these
changes (owner request); see their changelogs.

## Build inputs

- Toolchain: Rust 1.98.1 (`rust-toolchain.toml`), unchanged.
- Dependencies: unchanged since 1.1.0. The lockfiles differ only in
  QuickVault's own crate versions.
- Vendored: `dioxus-desktop` 0.7.10 with its local patch, changed for the
  numbered edit batches and the Linux editing-only context menu
  (`third-party/README.md`).

## Review status

Plan 0069 has had no fresh-context review. It changes the Android
background lock, the UI transport and copy/paste handling. No independent
security audit has been done.
